# Changelog

## [1.2.0] - 2026-11-19
### Added
- Добавлен блок «Отказ от курения»: журнал выкуренных сигарет, счётчик дней без сигарет, статистика и факты-достижения
- Добавлена плитка «Курение» на главный экран и миграция БД до версии 14

### Changed
- Статистика: блоки с нулевыми значениями (0/0) больше не показываются
- Статистика: расчёт «выполнено в день дедлайна или раньше» унифицирован для всего времени и периода
- `TabActivity` разбит на контроллеры задач, покупок и справочника; диалог задачи вынесен в `TaskFormDialog`

### Fixed
- В финансах можно перевести факт обратно в план (и тип «Факт/План» сохраняется при редактировании)
- В ленте «Дедлайн» на главном экране теперь отображаются просроченные задачи

### Fixed

## [1.1.0] - 2026-11-13
### Added
- Добавлена вкладка с быстрыми заметками (ни дедлайнов ни сроков ни важности)
- Добавлена вкладка с управлением подписками (ежемесячные платежи, статистика)
- Добавлена вкладка с управлением финансами (импорт подписок и покупок из других вкладок, статистика)
- Добавлена вкладка с управлением ЖКХ-платежами (расчеты, ведение статистики)

### Changed
- Изменено отображение меню - теперь есть вкладка с настройкой виджетов на главном меню
- На вкладках главного меню (стандартные) теперь отображается суммарное количество незакрытых задач внутри

### Fixed
- Исправлено падение приложения при удалении раздела из вкладок
- Задача, выполненная в день дедлайна, не считается просроченной
- Исправлен порядок задач во вкладке "Важное"
- Мелкие фиксы для оптимизации приложения
