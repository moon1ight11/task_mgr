# TaskMGR
Локальное Android-приложение для управления задачами, покупками и справочной информацией. Всё хранится на устройстве в SQLite, без сети и аккаунтов.

## Возможности
- **Разделы и вкладки** — задачи группируются по разделам (Дом, Гараж, Авто, IT, Здоровье, Развлечения) и вкладкам внутри них
- **Задачи** — название, описание, приоритет (важно / обычно / потом), срок (точная дата, период, без срока), повтор
- **Повторы** — без повтора, по пробегу, по месяцам, по пробегу или месяцам; при выполнении автоматически создаётся следующая задача
- **Покупки** — название, цена, категория, отметка «куплено», сумма не купленного по категории и по вкладке
- **Справочник** — пары «название — значение» с категориями
- **Главный экран** — плитки разделов, вкладки «Дедлайн» (что горит или скоро) и «Важные» (приоритет «важно»)
- **Статистика** — сводка, разбивка по приоритетам и разделам, выполненное за период, покупки
- **Приватный раздел** — скрыт за паролем, разблокируется на сессию, при блокировке его вкладки исключаются из главного экрана
- **Локальное хранение** — SQLite на устройстве, без интернета и внешних сервисов

## Технологический стек
- **Основной язык** — Java 17
- **Платформа** — Android (minSdk 24, targetSdk 34)
- **База данных** — SQLite через `SQLiteOpenHelper`
- **UI** — Material 3, RecyclerView, View-адаптеры
- **Сборка** — Gradle (Groovy DSL), Android Gradle Plugin
- **Хранение секретов** — PBKDF2 (HMAC-SHA256 / SHA1 в зависимости от API) для пароля приватного раздела
- **Асинхронность** — собственный `DbExecutor` (один фоновый поток для SQLite + `Handler` на main)

## Архитектура
Проект разделён на слои по пакетам:
- **data** — `DatabaseHelper` (синглтон) и DAO (`data/dao/*`)
- **model** — модели данных (`Task`, `Tab`, `Section`, `ShoppingItem`, `ReferenceEntry`, `HistoryEntry`)
- **service** — бизнес-логика (`TaskService`, `UrgencyCalculator`, `TaskUrgencyComparator`)
- **ui** — экраны и адаптеры (`ui/main`, `ui/section`, `ui/tab`, `ui/stats`, `ui/common`)
- **util** — общие утилиты (`DbExecutor`, `PasswordHasher`, `AppLock`)

## Быстрый старт
### Предварительные требования
- JDK 17
- Android SDK (compileSdk 34)
- Android Studio или Gradle CLI

### Локальный запуск
**1. Клонировать репозиторий**

```Shell
git clone https://github.com/<username>/TaskMGR
cd TaskMGR
```
**2. Собрать debug-сборку**

```Shell
./gradlew assembleDebug
```
**3. Установить на устройство/эмулятор**

```Shell
./gradlew installDebug
```
Или открыть проект в Android Studio и запустить через Run.

## Особенности реализации
### Структура данных
- **Section** — раздел (Дом, Гараж, Авто, IT, Здоровье, Развлечения, Private)
- **Tab** — вкладка внутри раздела; для раздела «Авто» хранит год и текущий пробег
- **Task** — задача вкладки: приоритет, статус, тип срока, поля срока, правило повтора
- **ShoppingItem** — покупка вкладки: цена, категория, флаг «куплено»
- **ReferenceEntry** — запись справочника: название, значение, категория
- **HistoryEntry** — факт выполнения задачи: время, пробег на момент выполнения, заметка

### Приватный раздел
- Пароль хранится как PBKDF2-хеш (соль + итерации + хеш в `app_settings`), сам пароль не сохраняется
- Разблокировка действует на сессию (`AppLock`), сбрасывается при убийстве процесса
- При заблокированном приватном разделе его вкладки исключаются из главного экрана и статистики

### Выполнение задач и повторы
- Выполнение задачи пишет запись в историю, помечает задачу `done`, обновляет пробег вкладки (если передан) и при повторе создаёт следующую задачу
- Пробег вкладки не уменьшается: пишется только если новое значение больше текущего
- Поддерживаемые повторы: `by_km`, `by_months`, `by_km_or_months`; для `by_km_or_months` следующая задача получает и дату, и пробег, а срочность считается по худшей из оценок

### Целостность данных
- Выполнение задачи выполняется в одной SQLite-транзакции: история, статус, пробег и следующая задача — либо всё, либо ничего
- `DatabaseHelper` — синглтон на приложение (`applicationContext`), один экземпляр на процесс
- Внешние ключи включены (`onConfigure` → `setForeignKeyConstraintsEnabled(true)`), удаление вкладки каскадно удаляет её задачи, историю, покупки и справочник

### Срочность
- `UrgencyCalculator` определяет срочность: `OVERDUE` / `SOON` / `NORMAL` / `NONE`
- Для дат: просрочено, если срок в прошлом; «скоро» — в ближайшие 3 дня
- Для пробега: просрочено при остатке ≤ 0 км, «скоро» — ≤ 500 км
- `TaskUrgencyComparator` сортирует задачи: сначала `OVERDUE`, затем `SOON`, `NORMAL`, `NONE`; внутри группы — по расстоянию до дедлайна; задачи без срока — в конце

## Сборка
Проект использует Gradle wrapper. Если Gradle подхватывает не ту версию JDK, укажи её явно:
```properties
# gradle.properties (локально, не коммитить)
org.gradle.java.home=C:\\path\\to\\jdk-17
```
Или задай JAVA_HOME перед сборкой:
```Shell
$env:JAVA_HOME="C:\path\to\jdk-17"
./gradlew clean assembleDebug
```
Сборка без ошибок: ./gradlew clean assembleDebug.

## Планы по развитию
- [ ] **Проверка обновлений** — кнопка в настройках: приложение проверяет новую версию по GitHub Releases и предлагает скачать APK; установка — через системный установщик (пользователь подтверждает)
- [ ] **Настройка плиток** — выбор до 6 разделов для главного экрана из расширенного набора; приват и статистика закреплены всегда
- [ ] **Уведомления о дедлайнах** — локальные напоминания за заданное время до срока задачи: настройка «за сколько» (часы/дни) на уровне задачи или раздела, чтобы не пропустить важное
- [ ] **Менеджер подписок** — отдельный раздел со списком подписок: название, цена, периодичность и дата следующего списания; ежемесячные напоминания о платежах и сводка по сумме подписок
- [ ] **Менеджер финансов** — планирование бюджета на выбранный период: учёт доходов и расходов, разбивка по категориям, остаток на период и предупреждения при приближении к лимиту
